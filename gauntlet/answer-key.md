# Answer key

For work without a real reference: custom logic, a new tool, a design nobody has built before. Without a bar, a critic invents its own standard. So before the loop starts, a person answers the open decisions and writes them down here. The critic judges against this file.

The idea comes from the community. Matt Pocock's `wayfinder` skill turns a large effort into a map of open decisions; others combined that map with an answer key for the critic (for example `rstan251/gauntlet`, August 2026).

## How to fill it

Ask Claude to interview you first:

```text
Before we build, interview me about every decision that is still open for <goal>.
Ask one question at a time, offer options where you can, and write each answer to gauntlet/answer-key.md.
Stop when a critic could judge any result against this file without asking me.
```
